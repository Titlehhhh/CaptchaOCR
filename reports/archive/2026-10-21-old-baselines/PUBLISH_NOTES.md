# Заметки о публикации CaptchaOCR

* Полный датасет (46 типов, 4600 размеченных PNG) публикуется отдельно на Hugging Face:
  `Titlehhhh/captchaocr-dataset` (см. ADR 0004). В git остаются генераторы на Java 21,
  разметка `labels.jsonl` на каждый тип, 230 образцов в `dataset/samples/` и весь код
  обучения, бенчмарков и проверок. Скачать: `python tools\fetch_dataset.py`.
* Репозиторий приватный и открывает его владелец отдельной командой; ветка `main` содержит
  один корневой коммит, в `.git` нет объектов предыдущих ревизий.
* Локально прежняя история не сохранялась (`git reflog expire --expire=now --all` и
  `git gc --prune=now --aggressive`): восстановить её можно только с GitHub, пока репозиторий
  приватный, — `git fetch origin <sha-прежнего-коммита>`.
