# DSH_HARNESS — внутренняя заметка

**Этот файл не для публикации.** Он описывает, как DeepSeek Harness (DSH) читает этот
репозиторий: какие файлы попадают в контекст агента (`AGENTS.md`, `CONTINUE.md`, `llms.txt`,
`.agents/skills/**`), как устроен рендер инструкций и что репозиторий **не** может определить
сам (например, собственные субагенты).

Подробности намеренно не приводятся: это справочник по локальной установке конкретной машины
(пути к профилю, версии внутреннего пакета, маршрут модели), и в публичном репозитории ему
не место.

Правила работы агентов в этом репозитории — в [`../AGENTS.md`](../AGENTS.md); карта
репозитория — в [`INDEX.md`](INDEX.md).
