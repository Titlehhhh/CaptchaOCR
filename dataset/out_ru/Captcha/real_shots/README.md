# Captcha - no real shots yet

This folder is **empty**, and that is deliberate.

The reserved name `Captcha` is still ambiguous: SpigotMC alone has a dozen resources called
*Captcha*, and the one genuinely Russian plugin that does render an image
(`UCRAFTS/CaptchaPlugin`, 512x256 JPEG on a map) matches none of the 250x150 catalogue
families. Until that is settled there is nothing to keep here; the candidates and the
decision that is still open are written up in `reports/SITE_CAPTCHAS.md` section 7.6.
