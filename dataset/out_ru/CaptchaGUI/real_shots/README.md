# CaptchaGUI - no real shots, and none can exist

This folder is **empty**, and that is deliberate: `Supl1n/CaptchaGUI` renders **no image**.
On join it opens a 9-slot inventory titled `Captcha` with a single emerald block in a
random slot (1...7); clicking it clears the check, clicking anything else - or closing the
inventory - kicks the player. There is no captcha image to photograph.

The generated type in `dataset/out_ru/CaptchaGUI/clickblock/` is a *rendering* of that GUI,
not a capture of it. See `reports/SITE_CAPTCHAS.md` section 7.3.
